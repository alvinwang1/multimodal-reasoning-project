# Idea 4: generated text in place of the raw input (242 items)

Accuracy is the mean over the 3 option orders; 95% CIs from 10,000 bootstrap resamples over items; paired tests are sign-flip tests, Holm-adjusted. Times are per item on the L4: *answer* = the scoring pass (forward + preprocessing), *generate* = producing the text it reads (AST, Whisper, Qwen captions/descriptions), *end to end* adds reading the media files. Tokens: answering input tokens relative to the full input. Generated by `python -m src.final.idea4_analysis`.

## Break-even k: generate the text once, then answer k questions about the same clip

Cost per question C(k) = answer + generate / k, against answering from the raw image + audio every time (404 ms). Break-even k = the smallest k with C(k) <= the raw cost, i.e. generate / (raw answer - text answer) rounded up; *never* when answering from the text is not faster. Reading the media is needed either way and cancels out. Accuracy is not part of k: see *vs I+A*.
